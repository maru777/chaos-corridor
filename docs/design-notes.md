## 方針
- **確定**: 3D（Three.js）、ブラウザで動く。派手な演出を重視する。
- **確定**: 名前は仮名「ケイオスコリドール」。リポジトリ名は `chaos-corridor`。
- **確定**: 公開は GitHub Pages。ローカルで遊べる状態になってから公開する。
- **確定**: 見た目はリアル志向。背景・質感は画像、派手さはコード（粒子・光・揺れ・スロー）で出す。
- **確定**: 最初のテーマは宇宙。スキンの差し替えで地獄・天国なども作れるようにする。
- **確定**: 作る順は、基本ルール → 対 AI と 2 人対戦 → 能力ガチャ → 演出・UI → 能力を増やす → オンライン対戦。
- **確定**: 演出のスキップ設定、点滅を抑える設定は付けない（のちに必要なら再検討）。
- 経緯: ARC は友達が作ったコリドール系ゲーム。似た感じのものを、能力の追加と UI 改善で作る。

## 見た目の方式（確定）
- 方針: 写真のリアルさではなく、「宇宙っぽく見せる」絵として整える。コードだけで作る。
- 背景の星雲: 起動時に 1 回だけ描いて、立方体の画像にして貼る（毎フレームは計算しない）。明るさに上限を設け、白飛びさせない。色は青・紫・青緑。
- 星・宇宙塵・惑星: 星雲・星・塵・惑星をそれぞれ違う速さで動かし、奥行きと「進んでいる感じ」を出す。
- 盤は、宙に浮かぶ半透明のガラス板に、光る格子線と細い縁の線。星雲が透けて映る。
- コマ・壁は、ソリッドにしない。コマは光の核・殻・暈・輪、壁は半透明の障壁と明るい縁の線。
- 仕上げ: 光のにじみ（ブルーム）、画面の四隅を暗くする、細かい粒、端のわずかな色ずれ。
- 不採用: 実写の天の川の写真（ESO）。引き伸ばしでぼやけ、「画像感」が強く、光のコマ・壁とも合わなかった。コードだけの銀河の円盤も、白飛びしたので不採用。
- カメラは、スマホ（縦長）では盤が横幅に収まる距離にする。

## 世界観（宇宙テーマ・案）
- 宇宙ステーションの回廊が星々の間に浮かぶ。ゴールは対岸のワープゲート。
- 壁はエネルギー障壁、コマは探査機。

## スキンのデータ（案）
色、空、盤面の質感、コマ・壁の見た目、演出、効果音、BGM、能力の呼び名を 1 つにまとめる。

## 能力
- **確定**: 能力名は漢字で書き、横文字の読みを添える（例: 斜行《ダイアゴナル》）。使うとカットインが入る。
- **確定**: レア度は UNCOMMON / RARE / EPIC / LEGENDARY の 4 段階。
- **確定**: 開始時にガチャで 2 個持つ。
- 能力の一覧は下の案。読みは仮。
- **実装済み（UNCOMMON の 3 つ）**: 斜行、回収、電波妨害。残りは未実装。

### 能力の共通ルール（確定・実装済み）
- 能力を使うと、その手番を使う（1 手番に 1 つの行動）。
- 1 つの能力は 1 局に 1 回。使うと手札から消える。
- ガチャは種（シード）だけで決まる。同じ種なら、両者とも同じ手札になる（対人で共有できる）。まずレア度を重み（UNCOMMON 60、RARE 28、EPIC 10、LEGENDARY 2）で選び、その中から能力を選ぶ。1 人の中で同じ能力は重ならない。能力がまだ無いレア度は飛ばす。
- 壁は、置いた人（持ち主）を持つ。ハッシュにも含める。
- 能力を足すときは、`abilities.ts` にデータ、`rules.ts` に効果、`tests/` に単体テストを足す。

### 実装した 3 つの仕様
- 斜行: 斜めの隣のマスへ動く。横→縦、または縦→横のどちらかの道が、壁と相手のコマにふさがれていなければよい。動いた先がゴール行なら勝ち。
- 回収: 自分が置いた壁 1 枚を盤から戻す。壁の残り枚数が 1 増える。相手の壁は戻せない。
- 電波妨害: 相手は、次の手番に壁を置けない（動く・能力は使える）。その手番が終わると解ける。すでに封じている相手には重ねて使えない。

| レア | 名前 | 読み | 効果 |
|---|---|---|---|
| UNCOMMON | 斜行 | ダイアゴナル | 斜めに 1 回動く |
| UNCOMMON | 回収 | リクレイム | 置いた自分の壁を 1 枚戻す |
| UNCOMMON | 電波妨害 | ジャミング | 相手の次の壁設置を封じる |
| RARE | 跳躍 | リープ | 壁を越えて 2 マス先へ |
| RARE | 鉄壁 | イージス | 自分の壁 1 枚を撤去・破壊不可にする |
| RARE | 隕石 | メテオ | 相手の前のマス 1 つを 3 ターン通行不可にする |
| EPIC | 超新星 | ノヴァ | 1 ターンに 2 回動く |
| EPIC | 虚無 | ヴォイド | 盤上の壁 1 枚を消す |
| EPIC | 引力 | グラビティ | 相手コマを 1 マス引き戻す |
| EPIC | 時停 | ステイシス | 相手を 1 ターン休ませる |
| EPIC | 三連壁 | トライウォール | 1 マス分の壁を 3 回まで置ける（解釈を確認中） |
| LEGENDARY | 混沌 | ケイオス | 盤上の壁を全部ランダムに置き直す |
| LEGENDARY | 天地反転 | インバート | 盤面を 180 度回す |

- 重要: 壁を動かす能力は、「どちらのコマもゴールまでの道が残る」ことを毎回検証する。ルールの核として最初に作る。

## カットイン演出（実装済み）
| レア | 長さ | 演出 |
|---|---|---|
| UNCOMMON | 約 1.8 秒 | 細い帯、画面を少し暗くする、帯の縁を走る小さな稲妻（4 本） |
| RARE | 約 2.4 秒 | 左右いっぱいの帯、画面端の光、小さなズーム、稲妻 8 本 |
| EPIC | 約 3.2 秒 | 暗転、名前の大書、粒の飛び散り、淡い閃光、カメラの揺れとズーム、稲妻 16 本（上下から帯へ落ちる稲妻を含む） |
| LEGENDARY | 約 4.6 秒 | 強い暗転、スロー、じわじわズーム、金色の光の縁、閃光、粒の飛び散り、カメラの揺れ、長い効果音、稲妻 30 本 |

- 名前が決まってから、1.2 秒以上は画面に残す（読めるように。テストで保証）。
- 帯は傾けず、左右いっぱいに広げる（端が斜めの線に見えないように）。
- 稲妻は、線の中点をずらす方法でギザギザにし、2 回ほどちらつきながら光って消える（連続した点滅ではない）。形と出るタイミングの計算は `view/bolt.ts`（テストあり）。

- 能力を使ったときだけ出る。名前は漢字、横文字の読みを《 》で添える。帯の色は使った人（先手 青・後手 桃）、縁取りはレア度の色。
- 状態は能力を使った瞬間に確定する。盤の見た目は、カットインの見せ場で切り替える。演出中は操作を受け付けない（二重操作を防ぐ）。
- 効果音は外部の素材を使わず、ブラウザの音声機能で合成する（音量は控えめ、レア度が高いほど長く厚い）。
- 閃光は 1 回だけで、連続した点滅はしない。OS の「視差効果を減らす」設定では、揺れ・ズーム・スロー・粒・閃光をなくす（演出のスキップ設定や、点滅を抑える専用の設定は付けない決定のまま）。
- デバッグモード: 右上の DEBUG ボタン（または URL に `?debug`）で開く。公開前に外す。
  - レア度ごとのカットインを、何回でも試せる（演出中でも押し直せる。数字キー 1〜4 でも可。対局には影響しない）。
  - 実際の能力を使うときの演出のレア度を、好きなものに変えられる。
  - 「能力を使っても減らさない」で、何回でも能力を使える（操作の記録には入れない）。
- 演出の強さの計算は、描画から切り離して `view/impact.ts` に置き、テストしている。

## テスト（確定）
- 背景: ARC を対人で遊んだとき、相手と障害物の位置が違う、不具合が出る、といった問題があった。
- 規則は描画から切り離し、同じ状態＋同じ操作 → 同じ結果になるようにする。ランダムは種つきで再現できる。
- 操作の記録を再生すると同じ状態になることをテストする。
- 対人は、毎ターン状態のハッシュを比べて、ずれを検出する。
- 能力・障害物・特殊マスは、単体テストと、ボット同士の大量対局（道の消失・規則違反・ずれの検出）で確認する。
- 詳細は [CLAUDE.md](../CLAUDE.md) の「テスト方針」。
